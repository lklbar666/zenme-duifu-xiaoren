# 怎么对付小人 - 人际博弈方法论 Skill

基于《怎样对付小人》（张胜利、岳贵安主编，延边人民出版社）提炼的人际博弈方法论Skill。涵盖辨识、揭批、制服、智胜、设计、避让、利用七大策略体系，从中国历史案例中提取可操作的识人术、反击术、权谋术、隐忍术与化敌为友术。

## 核心功能

- **七大策略体系**：辨识→揭批→制服→智胜→设计→避让→利用
- **八征识人法**：源自姜太公的系统识人框架
- **七类小人特征**：快速识别不同类型小人
- **80+具体方法**：每种策略下都有可操作的具体方法
- **决策矩阵**：根据力量对比自动推荐应对策略
- **历史案例**：从阿合马、哈麻、王旦等历史人物中提炼智慧

## 适用场景

- 职场冲突与办公室政治
- 人际博弈与权力斗争
- 小人防范与应对
- 人脉经营与化敌为友
- 自我保护与隐忍策略

1. 加载Skill后，先进行力量评估（权力、资源、道理三个维度）
2. 根据评估结果选择对应策略模块

4. 执行前确认不违反法律和道德底线

## 七大策略总览

| 策略 | 核心理念 | 适用力量对比 |
|---|---|---|
| 辨识 | 先识后制，知人善任 | 所有场景 |
| 揭批 | 有理有据，攻其不备 | 有证据时 |
| 制服 | 用权有度，一击必中 | 力量占优 |
| 智胜 | 逆向思维，不战而胜 | 力量相当 |
| 设计 | 欲擒故纵，诱导犯错 | 主动出击 |
| 避让 | 隐忍待时，保存实力 | 力量劣势 |
| 利用 | 化敌为友，借力打力 | 有共同利益 |
