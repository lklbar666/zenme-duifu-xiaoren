## 力量评估快速判断

**问自己三个问题**：
1. 谁的权力更大？（制度权力）
2. 谁的资源更多？（人脉、金钱、信息）
3. 谁更占理？（道德、规则、证据）

**决策规则**：
- 3项占优 → 直接制服
- 2项占优 → 智胜为主
- 1项占优 → 避让为主
- 0项占优 → 深度避让，等待时机

## 应对小人的底线

**绝对不能做的事**：
1. 违法乱纪（陷害、诬告、暴力）
2. 损害无辜第三方
3. 丧失自己的道德底线
4. 为了对付小人变成小人

**可以做的事**：
1. 正当防卫
2. 合法合规的反击
3. 保护自己的利益
4. 利用规则和制度

## 时机判断

**该出手时**：
- 对方行为已经造成实际损害
- 你有确凿证据
- 力量对比对你有利
- 时机成熟，一击必中

**该忍耐时**：
- 证据不足
- 力量对比不利
- 时机不成熟
- 出手后损失大于收益

## 一句话心法

- **辨识**：听其言，观其行，察其变
- **揭批**：用事实说话，不情绪化
- **制服**：出手要快、准、狠
- **智胜**：不战而屈人之兵
- **设计**：欲使其亡，先使其狂
- **避让**：留得青山在，不怕没柴烧
- **利用**：化敌为友，变废为宝
