# 应对模式与技巧

## 模式1：先识后制

**适用场景**：不确定对方是否是小人，或刚进入新环境
**操作步骤**：
1. 用八征法中的2-3种观察对方
2. 对照七类小人特征进行匹配
3. 确认后再选择应对策略
**关键**：不急于下结论，也不毫无防备

## 模式2：力量评估决策

**适用场景**：已经确认对方是小人，需要选择应对方式
**决策矩阵**：

| 你的力量 | 对方力量 | 推荐模块 | 具体方法 |
|---|---|---|---|
| 强 | 弱 | 制服 | 用权、擒王、冷不防 |
| 强 | 强 | 智胜+制服 | 分化、离间、抓过错 |
| 相当 | 相当 | 智胜 | 逆向思维、捧杀、拖延 |
| 弱 | 强 | 避让 | 隐忍、扮猪吃虎、低调 |
| 弱 | 弱 | 避让+利用 | 不冲突，寻找共同利益 |

## 模式3：证据先行反击

**适用场景**：需要公开揭批小人
**操作步骤**：
1. 收集确凿证据（邮件、记录、证人）
2. 选择合适时机（公开场合、第三方在场）
3. 用事实和数据说话，不带情绪
4. 一次到位，不给对方反驳机会
5. 留好退路，防止对方反咬

## 模式4：扮猪吃虎全流程

**适用场景**：力量劣势，需要等待时机
**操作步骤**：
1. **伪装期**：表现得无能、无害、低调
2. **积累期**：默默提升实力，收集对方把柄
3. **麻痹期**：持续示好，让对方轻视你
4. **等待期**：等待对方犯错或力量对比变化
5. **出手期**：在关键时刻一击必中

## 模式5：捧杀诱导

**适用场景**：对方自负、爱听好话
**操作步骤**：
1. 公开场合过度赞美
2. 赋予超出能力的责任或头衔
3. 等待其骄傲犯错
4. 在其犯错时收集证据
5. 选择合适时机揭露

## 模式6：离间分化

**适用场景**：对方有联盟或小团体
**操作步骤**：
1. 找到联盟内部的利益分歧
2. 逐个沟通，制造信息差
3. 故意传递暧昧信息
4. 让他们互相猜疑
5. 在其内斗时坐收渔利

## 模式7：化敌为友

**适用场景**：对方有可用价值，或消灭成本太高
**操作步骤**：
1. 找到对方的核心需求
2. 在关键时刻提供帮助
3. 不要求即时回报
4. 持续投入，建立信任
5. 寻找共同利益，创造合作机会
6. 用时间和诚意化解矛盾

## 模式8：激流勇退

**适用场景**：已达到目标，继续留下风险增大
**判断信号**：
- 功高震主
- 对手开始抱团
- 环境发生不利变化
- 自己已获得足够利益
**操作**：主动让出位置，保留成果和名声

## 通用技巧

### 沟通技巧
- **倾听优先**：先听对方说，抓逻辑漏洞
- **短句回应**：不绕弯，不情绪化
- **不人身攻击**：只批行为，不批人格
- **留有余地**：不把话说死，给对方台阶

### 自保技巧
- **所有行为留痕**：邮件、记录、文件
- **不参与传闲话**：避免被卷入
- **保持财务廉洁**：不给对方把柄
- **建立自己的人脉**：关键时刻有人帮

### 心理技巧
- **情绪稳定**：不被对方激怒
- **长期视角**：不计较一时得失
- **底线思维**：明确什么不能退
- **机会主义**：随时准备抓住对方的错误

## 反模式清单

| 反模式 | 为什么错 | 正确做法 |
|---|---|---|
| 情绪化反击 | 失去理性，被抓把柄 | 冷静收集证据 |
| 无证据指控 | 反被诬告诽谤 | 先取证再行动 |
| 只打外围 | 核心未除，春风吹又生 | 擒贼先擒王 |
| 用权过度 | 引起公愤，反被推翻 | 用权有度 |
| 无底线忍耐 | 丧失原则和尊严 | 明确底线 |
| 利用太明显 | 对方察觉后反目 | 真诚投入 |
| 赶尽杀绝 | 狗急跳墙，鱼死网破 | 留有余地 |
| 骄傲轻敌 | 被扮猪吃虎的人反杀 | 始终保持警惕 |
