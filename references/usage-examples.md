# 使用示例

```plaintext
=== 示例1：辨识职场小人 ===

用户：我们部门新来一个同事，总在领导面前表现，背后说人坏话，怎么判断他是不是小人？

Skill执行：
1. 调用ch01辨识模块
2. 推荐使用八征法中的3种：
   - 间之以辞：和他闲聊，看他如何评价不在场的同事
   - 与之间谍：分享一个无关紧要的"秘密"，看他是否传播
   - 使之以财：观察他对利益分配的态度
3. 对照七类小人特征：他符合"巧言令色型"+"阿谀奉承型"
4. 结论：大概率是小人，建议保持距离，不深交，不留把柄


=== 示例2：被小人背后捅刀后的反击 ===

用户：同事在领导面前告我黑状，说我项目延期是我的责任，实际是他不配合，怎么办？

Skill执行：
1. 评估力量：平级，力量相当 → 智胜+揭批
2. 调用ch02揭批模块：
   - 收集证据：项目记录、邮件、聊天记录
   - 用事实揭穿谎言
   - 帮他算笔账：列出他不配合的具体时间点和影响
3. 调用ch04智胜模块：
   - 反过来试试：主动在领导面前肯定他的"贡献"，然后客观陈述事实
   - 把皮球踢还给他："这个问题我们可以一起复盘一下当时的情况"
4. 执行：在项目复盘会上，用数据说话，不情绪化，一次到位


=== 示例3：下属是小人，如何制服 ===

用户：我的下属总是阳奉阴违，当面答应背后不做，还挑拨其他同事关系，怎么办？

Skill执行：
1. 评估力量：你是上级，力量占优 → 制服
2. 调用ch03制服模块：
   - 有权用权：明确职责，设置KPI，书面确认
   - 擒贼先擒王：如果他是小团体核心，重点对付他
   - 抓住过错治对手：收集他未完成任务的证据
   - 杀一儆百：公开处理，震慑其他人
3. 执行步骤：
   - 第一次：私下警告，书面记录
   - 第二次：公开批评，扣绩效
   - 第三次：按制度处理，调岗或辞退
4. 注意：用权要合规，不留把柄


=== 示例4：力量劣势时如何避让 ===

用户：我的上级是个小人，总是给我穿小鞋，抢我的功劳，我又不能辞职，怎么办？

Skill执行：
1. 评估力量：对方是上级，力量悬殊 → 避让
2. 调用ch06避让模块：
   - 夹起尾巴做人：低调，不抢风头
   - 羽翼未丰且忍耐：默默积累实力，寻找外部机会
   - 扮猪吃虎：表现得无害，让他轻视你
   - 不给他红眼的机会：不在他面前炫耀成绩
3. 同时调用ch07利用模块：
   - 投其所好：了解他的需求，适度满足
   - 留给他几分面子：公开场合给他面子
   - 借助"第三者"之力：和他的上级或同级建立良好关系
4. 长期策略：积累实力，等待时机，要么他调走，要么你有更好的机会


=== 示例5：如何利用小人为你做事 ===

用户：团队里有个能力很强但人品一般的人，怎么让他为项目出力？

Skill执行：
1. 评估：对方有能力，有利用价值 → 利用
2. 调用ch07利用模块：
   - 鸡鸣狗盗也是才：识别他的特长，放在合适位置
   - 重赏之下有勇夫：设置明确的奖励机制
   - 但求结果，不问动机：不要求他道德高尚，只看结果
   - 留给他几分面子：不在公开场合批评他
3. 管理策略：
   - 用其所长，避其所短
   - 制度约束，不依赖个人自觉
   - 关键环节多人把关，防止他搞鬼
   - 及时兑现承诺，保持激励有效


=== 示例6：小人抱团，如何分化 ===

用户：部门里有三个人抱团，总是一起针对我，怎么办？

Skill执行：
1. 评估：对方3人抱团，你1人 → 智胜
2. 调用ch04智胜模块：
   - 拆散联盟：找到他们内部的利益分歧
   - 离间计：逐个沟通，制造信息差
   - 使敌狐疑：故意制造暧昧信息，让他们互相猜疑
3. 具体操作：
   - 观察三人中谁是核心，谁是跟随
   - 对跟随者示好，孤立核心
   - 在分配任务时，让他们产生利益冲突
   - 等待他们内斗，坐收渔利
4. 注意：分化要自然，不表现得太刻意


=== 示例7：综合应用——职场生存全流程 ===

用户：刚加入一家新公司，如何系统性地应对可能遇到的小人？

Skill执行：
1. **第一阶段（入职1-3个月）：辨识**
   - 用八征法观察每位同事
   - 识别小人和盟友
   - 低调做人，不站队

2. **第二阶段（3-6个月）：避让+利用**
   - 对小人保持距离，不深交
   - 对有价值的人主动建立关系
   - 积累业绩，建立信誉

3. **第三阶段（6个月后）：择机行动**
   - 如果小人主动挑衅 → 揭批+智胜
   - 如果你获得权力 → 制服
   - 如果小人有利用价值 → 利用
   - 如果环境太差 → 激流勇退，寻找新机会

4. **始终坚持**：
   - 身正不怕影子斜
   - 所有行为留痕
   - 不丧失底线
   - 长期视角，不计较一时得失
```
